# Bullfrog FC — web
Web estática de Bullfrog FC / BFC / Las Ranitas.

## Estructura
- index.html
- styles.css
- script.js
- assets/escudo.png

## Editar
Los jugadores, cuerpo técnico y datos del club están directamente en `index.html`.
Los colores principales se encuentran al principio de `styles.css` como variables CSS.

No necesita servidor: abre `index.html` en el navegador.
